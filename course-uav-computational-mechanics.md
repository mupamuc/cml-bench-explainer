# Часть I. Математические основы численных методов

## Модуль 1. Дискретизация, погрешность, устойчивость, сходимость

**Цели обучения.** По завершении студент умеет: классифицировать источники
погрешности; оценивать порядок аппроксимации разностной схемы; анализировать
устойчивость по фон Нейману; отличать сходимость от устойчивости и связывать их
теоремой Лакса.

**Теория.**

- Погрешность округления vs погрешность дискретизации (усечения). Машинный эпсилон,
  катастрофическая потеря значимости.
- Конечные разности из ряда Тейлора: вперёд/назад/центральная, порядок точности
  `O(h)`, `O(h²)`.
- Обусловленность задачи и устойчивость алгоритма — разные вещи.
- **Теорема эквивалентности Лакса:** для корректно поставленной линейной задачи
  согласованность + устойчивость ⇔ сходимость.

**Ключевые соотношения.**

Центральная разность второй производной:

```
f''(x) ≈ (f(x+h) - 2f(x) + f(x-h)) / h²  + O(h²)
```

Явная схема для уравнения теплопроводности и её условие устойчивости (число Куранта
для диффузии):

```
r = α·Δt / Δx²  ≤  1/2   (устойчивость явной схемы)
```

**Лабораторная 1.** На Python: (а) численно продифференцировать функцию, построить
график погрешности от `h` в log–log, найти оптимальный `h` (баланс усечения и
округления); (б) решить 1D-уравнение теплопроводности явной и неявной схемами,
показать разрушение решения при нарушении `r ≤ 1/2`.

**Критерий освоения.** Наклон кривой погрешности совпадает с теоретическим порядком;
студент объясняет, почему уменьшение `h` за пределом оптимума ухудшает результат.

**Источники.** LeVeque «Finite Difference Methods for ODEs and PDEs»; Trefethen «Numerical
Linear Algebra».

## Модуль 2. Численная линейная алгебра и решение больших систем

**Цели обучения.** Выбирать прямой или итерационный решатель под задачу; понимать
влияние обусловленности; применять предобуславливание.

**Теория.**

- Прямые методы: LU, разложение Холецкого для симметричных положительно определённых
  матриц (типично для МКЭ-жёсткости).
- Разрежённость матриц МКЭ/МКО; форматы хранения (CSR).
- Итерационные методы: сопряжённые градиенты (CG) для SPD, GMRES для несимметричных.
- Предобуславливатели (Jacobi, ILU, AMG) и число обусловленности как множитель числа
  итераций.

**Ключевые соотношения.**

Оценка сходимости CG через число обусловленности `κ`:

```
‖e_k‖_A / ‖e_0‖_A  ≤  2·((√κ − 1)/(√κ + 1))^k
```

**Лабораторная 2.** Собрать разрежённую SPD-матрицу (1D/2D Пуассон), сравнить прямой
решатель SciPy, CG без и с предобуславливанием; построить число итераций от размера
сетки.

**Критерий освоения.** Студент обосновывает выбор решателя и демонстрирует ускорение
от предобуславливания.

**Источники.** Saad «Iterative Methods for Sparse Linear Systems»; документация SciPy
`scipy.sparse.linalg`.

# Часть II. Конечно-элементный анализ конструкции

## Модуль 3. Основы МКЭ: слабая форма, сборка, граничные условия

**Цели обучения.** Вывести слабую форму краевой задачи; построить элементные матрицы;
собрать глобальную систему; корректно наложить условия Дирихле/Неймана.

**Теория.**

- Сильная → слабая (вариационная) форма, пространство пробных функций.
- Метод Галёркина, базисные функции (линейные/квадратичные), изопараметрическое
  отображение, численное интегрирование по Гауссу.
- Сборка глобальной матрицы жёсткости `K` и вектора нагрузок `F`.
- Существенные (Дирихле) и естественные (Нейман) граничные условия.

**Ключевое уравнение.** Линейная статика:

```
K · u = F
```

где `K` — матрица жёсткости (SPD после наложения ГУ), `u` — узловые перемещения,
`F` — узловые силы.

**Лабораторная 3.** В FEniCSx решить задачу о растяжении/изгибе консольной балки;
сравнить с аналитикой Эйлера–Бернулли; изучить сходимость по сетке (h-refinement).

**Критерий освоения.** Численный прогиб сходится к аналитическому; студент показывает
монотонное уменьшение погрешности при измельчении.

**Источники.** Zienkiewicz & Taylor «The Finite Element Method»; Hughes «The Finite
Element Method»; учебник FEniCS (Langtangen & Logg).

## Модуль 4. Прочность и жёсткость планёра БПЛА. Композиты

**Цели обучения.** Ставить задачу прочности рамы/крыла; работать с ортотропными
композитными материалами; интерпретировать поля напряжений и критерии разрушения.

**Теория.**

- 3D-упругость, критерий фон Мизеса для металлов.
- Слоистые композиты: теория ламината (CLT), матрицы `A, B, D`; ориентация слоёв.
- Критерии разрушения композитов: Tsai–Wu, максимальных напряжений.
- Концентраторы напряжений (отверстия под крепёж, стыки лонжерона).

**Ключевое соотношение.** Определяющее соотношение ортотропного слоя (в осях материала):

```
σ = Q · ε ,   Q — матрица жёсткости слоя (E1, E2, G12, ν12)
```

**Лабораторная 4.** В CalculiX (или FEniCSx): расчёт крыла/рамы квадрокоптера под
аэродинамической + инерционной нагрузкой; определить запас прочности; для композитного
крыла оценить индекс разрушения Tsai–Wu.

**Критерий освоения.** Студент находит критическую зону, обосновывает запас прочности и
предлагает конструктивное улучшение.

**Источники.** Jones «Mechanics of Composite Materials»; документация CalculiX (CGX/CCX).

---

## Модуль 5. Модальный анализ и вибрации винтомоторной группы

**Цели обучения.** Проводить модальный анализ; оценивать риск резонанса с частотой
вращения винта; учитывать демпфирование.

**Теория.**

- Обобщённая задача на собственные значения:

```
(K − ω²·M) · φ = 0
```

  где `M` — матрица масс, `ω` — собственные частоты, `φ` — формы колебаний.
- Диаграмма Кэмпбелла: пересечение собственных частот с гармониками оборотной частоты
  винта (`1P`, `2P`, `nP`).
- Вынужденные колебания и передаточные функции; влияние демпфирования.

**Лабораторная 5.** Модальный анализ рамы БПЛА; построить первые 5 форм и частот;
наложить рабочий диапазон оборотов винта, выявить опасные резонансы; предложить отстройку
(жёсткость/масса).

**Критерий освоения.** Студент строит диаграмму Кэмпбелла и обоснованно указывает
безопасный диапазон оборотов.

**Источники.** Rao «Mechanical Vibrations»; методические материалы по rotordynamics.

# Часть III. Вычислительная аэро- и гидродинамика (CFD)

## Модуль 6. Уравнения течения, метод конечных объёмов, сетки

**Цели обучения.** Понимать законы сохранения в интегральной форме; строить и оценивать
качество сетки; запускать базовый расчёт в OpenFOAM.

**Теория.**

- Уравнения Навье–Стокса: сохранение массы, импульса, энергии.
- Метод конечных объёмов (МКО): интегрирование по контрольному объёму, потоки через
  грани, схемы дискретизации (upwind, central, limited).
- Сетки: структурированные/неструктурированные, пограничный слой (inflation layers),
  качество (skewness, non-orthogonality, `y+`).
- Алгоритмы связки давление–скорость: SIMPLE, PIMPLE.

**Ключевое соотношение.** Число Куранта (ограничение шага для явных/переходных схем):

```
CFL = U·Δt / Δx  ≤  1   (типичный порог для переходных расчётов)
```

**Лабораторная 6.** OpenFOAM: обтекание цилиндра/профиля при малом Re, ламинарный
режим; построить поля скорости и давления в ParaView; проверить сеточную независимость.

**Критерий освоения.** Решение не зависит от дальнейшего измельчения сетки; студент
контролирует сходимость по невязкам.

**Источники.** Ferziger & Perić «Computational Methods for Fluid Dynamics»; Versteeg &
Malalasekera «An Introduction to CFD: The Finite Volume Method»; руководство пользователя
OpenFOAM.

## Модуль 7. Турбулентность: RANS и LES

**Цели обучения.** Выбирать модель турбулентности под задачу; понимать компромисс
точность/стоимость; корректно задавать пристеночное разрешение.

**Теория.**

- Осреднение по Рейнольдсу (RANS), проблема замыкания, тензор рейнольдсовых напряжений.
- Модели: `k–ε`, `k–ω SST` (стандарт для внешней аэродинамики), Spalart–Allmaras.
- Пристеночные функции vs разрешение до стенки; требования к `y+`.
- LES: разрешение крупных вихрей, подсеточные модели; стоимость на порядки выше RANS.
- Гибриды (DES/DDES) как компромисс.

**Ключевое различие.** RANS даёт осреднённое стационарное поле дёшево; LES разрешает
нестационарные структуры дорого. Для инженерных оценок аэродинамики БПЛА базово —
`k–ω SST`.

**Лабораторная 7.** OpenFOAM: обтекание аэродинамического профиля (например, из серии
NACA) в турбулентном режиме моделью `k–ω SST`; получить поляру `Cl(α)`, `Cd(α)`;
сравнить с экспериментальными/справочными данными; проверить `y+`.

**Критерий освоения.** `y+` в целевом диапазоне выбранной модели; расчётные `Cl`, `Cd`
согласуются со справочными в пределах разумной погрешности.

**Источники.** Wilcox «Turbulence Modeling for CFD»; Menter (1994) — модель SST;
база данных профилей и поляр*.

## Модуль 8. Аэродинамика несущих поверхностей и винта

**Цели обучения.** Рассчитывать характеристики крыла конечного размаха и воздушного
винта; применять как быстрые инженерные методы, так и CFD.

**Теория.**

- Крыло конечного размаха: индуктивное сопротивление, теория несущей линии Прандтля.
- Быстрые методы: панельные методы, вихревая решётка (VLM), теория элемента лопасти
  (BEMT) для винта.
- CFD винта: подходы MRF (Multiple Reference Frame) для квазистационарного и sliding
  mesh для нестационарного расчёта.
- Тяга, крутящий момент, КПД винта; влияние числа оборотов и шага.

**Ключевые соотношения.** Аэродинамические коэффициенты и тяга/момент винта:

```
L = ½·ρ·V²·S·Cl ,   D = ½·ρ·V²·S·Cd
T = C_T·ρ·n²·D⁴ ,   Q = C_Q·ρ·n²·D⁵     (n — об/с, D — диаметр винта)
```

**Лабораторная 8.** (а) VLM/BEMT-расчёт крыла и винта на Python; (б) CFD-расчёт винта в
OpenFOAM с MRF; сопоставить тягу и момент двух подходов, обсудить расхождения.

**Критерий освоения.** Студент объясняет источники расхождения быстрого метода и CFD и
границы применимости каждого.

**Источники.** Anderson «Fundamentals of Aerodynamics»; Leishman «Principles of Helicopter
Aerodynamics» (винт); документация BEMT-библиотек.

# Часть IV. Полётная динамика и управление

## Модуль 9. 6-DOF модель движения БПЛА

**Цели обучения.** Выводить уравнения движения твёрдого тела; численно интегрировать
траекторию; линеаризовать модель вокруг режима.

**Теория.**

- Системы координат (связанная, земная), углы Эйлера и кватернионы (обход
  gimbal lock).
- Уравнения Ньютона–Эйлера: 6 степеней свободы (3 линейные + 3 угловые).
- Аэродинамические силы и моменты как функции состояния и управления.
- Численное интегрирование: явный/неявный Рунге–Кутта (RK4), выбор шага, устойчивость
  жёстких систем.
- Линеаризация, продольный и боковой каналы.

**Ключевое уравнение.** Динамика вращения (уравнение Эйлера):

```
I·ω̇ + ω × (I·ω) = M
```

где `I` — тензор инерции, `ω` — угловая скорость, `M` — суммарный момент.

**Лабораторная 9.** На Python (SciPy `solve_ivp`): симуляция 6-DOF модели БПЛА
(фиксированное крыло или мультикоптер); построить отклик на управляющее воздействие;
сравнить RK4 с адаптивным интегратором.

**Критерий освоения.** Траектория физически корректна (сохранение энергии в свободном
режиме); студент обосновывает выбор интегратора и шага.

**Источники.** Stevens & Lewis «Aircraft Control and Simulation»; Beard & McLain «Small
Unmanned Aircraft: Theory and Practice».

# Часть V. Мультифизика и оптимизация

## Модуль 11. Аэроупругость и связанные задачи (FSI)

**Цели обучения.** Понимать взаимодействие потока и конструкции; ставить связанную
задачу; распознавать аэроупругие неустойчивости.

**Теория.**

- Классификация FSI: одностороннее (1-way) и двустороннее (2-way) связывание.
- Статическая аэроупругость: дивергенция крыла, эффективность органов управления.
- Динамическая аэроупругость: флаттер — потеря устойчивости при связке изгибной и
  крутильной форм.
- Схемы связывания решателей CFD↔FEM, обмен нагрузками/перемещениями на интерфейсе,
  устойчивость связанной итерации.

**Ключевая идея.** Флаттер возникает, когда аэродинамические силы подкачивают энергию в
конструкцию быстрее, чем она рассеивается демпфированием → критическая скорость флаттера.

**Лабораторная 11.** 1-way FSI: перенести аэродинамическую нагрузку из CFD-расчёта крыла
(Модуль 7/8) на КЭ-модель (Модуль 4), получить деформацию; обсудить, что изменит 2-way
связывание.

**Критерий освоения.** Студент корректно переносит поле давления на КЭ-сетку и объясняет
ограничения одностороннего подхода.

**Источники.** Bisplinghoff, Ashley & Halfman «Aeroelasticity»; Hodges & Pierce
«Introduction to Structural Dynamics and Aeroelasticity».

## Модуль 12. Оптимизация конструкции: топологическая и параметрическая

**Цели обучения.** Формулировать задачу оптимизации с ограничениями; применять
топологическую оптимизацию и адъоинт-методы; понимать трейд-оффы масса/прочность/
аэродинамика.

**Теория.**

- Постановка: целевая функция, проектные переменные, ограничения (масса, напряжение,
  прогиб).
- Топологическая оптимизация: метод SIMP (штраф плотности), минимизация податливости
  при ограничении объёма.
- Градиентные методы и чувствительности; **адъоинт-метод** — стоимость градиента не
  зависит от числа переменных (ключ для CFD-оптимизации формы).
- Многокритериальность: фронт Парето, трейд-офф масса↔сопротивление↔прочность.

**Ключевое соотношение.** Каноническая постановка:

```
min  f(x)      (напр. масса или сопротивление)
s.t. g_i(x) ≤ 0   (прочность, прогиб, объём)
     x_min ≤ x ≤ x_max
```

**Лабораторная 12.** (а) Топологическая оптимизация кронштейна БПЛА (SIMP, Python/
open-source); (б) знакомство с адъоинт-оптимизацией формы профиля в SU2; построить фронт
Парето для 2 критериев.

**Критерий освоения.** Студент интерпретирует оптимальную топологию как силовой путь и
объясняет позицию решения на фронте Парето.

**Источники.** Bendsøe & Sigmund «Topology Optimization»; Sigmund «99-line topology
optimization code»; документация SU2 (adjoint).

# Часть VI. Инженерная практика расчёта

## Модуль 13. Верификация, валидация и воспроизводимость (V&V)

**Цели обучения.** Отличать верификацию от валидации; количественно оценивать сеточную
погрешность; обеспечивать воспроизводимость расчёта.

**Теория.**

- **Верификация** («решаем ли уравнения правильно») vs **валидация** («правильные ли
  уравнения решаем» — сравнение с экспериментом).
- Сеточная сходимость и индекс сходимости Ричардсона (GCI).
- Оценка неопределённости: численная, модельная, входных данных.
- Воспроизводимость: контроль версий (git) расчётных кейсов, фиксация версий решателей,
  скриптование пайплайна, документирование сеток и настроек.

**Ключевое соотношение.** Экстраполяция Ричардсона по трём сеткам с порядком `p`:

```
f_exact ≈ f_1 + (f_1 − f_2) / (r^p − 1)
```

где `r` — коэффициент измельчения сетки.

**Лабораторная 13.** Провести формальное исследование сеточной сходимости для одного из
прежних CFD/FEM-кейсов; рассчитать GCI; оформить расчёт как воспроизводимый git-репозиторий
со скриптами запуска.

**Критерий освоения.** Студент приводит численную погрешность с доверительной оценкой и
демонстрирует запуск «с нуля» по README.

**Источники.** Roache «Verification and Validation in Computational Science and
Engineering»; Oberkampf & Roy «Verification and Validation in Scientific Computing»;
руководства ASME V&V 20 / AIAA.

# Итоговый проект (сквозной кейс)

**Задача.** Выбрать конкретный БПЛА (фиксированное крыло, мультикоптер или VTOL) и провести
полный цикл вычислительной механики:

1. **Аэродинамика** — CFD-расчёт несущей поверхности и/или винта, получение нагрузок и
   характеристик (Модули 6–8).
2. **Прочность** — КЭ-расчёт планёра под полученными нагрузками, оценка запасов, при
   необходимости композитный анализ (Модули 3–4).
3. **Динамика** — модальный анализ и отстройка от резонанса винта (Модуль 5);
   6-DOF-симуляция и синтез стабилизирующего автопилота (Модули 9–10).
4. **Связывание и оптимизация** — 1-way FSI и оптимизация одного узла конструкции или
   формы профиля (Модули 11–12).
5. **V&V** — исследование сеточной сходимости и оформление всего пайплайна как
   воспроизводимого репозитория (Модуль 13).

**Результат.** Технический отчёт + git-репозиторий расчётов + защита. Оценивается
корректность постановок, обоснованность численных настроек, качество V&V и инженерная
интерпретация результатов.
